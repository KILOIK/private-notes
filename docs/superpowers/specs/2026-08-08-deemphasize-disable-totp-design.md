# 弱化“关闭二次验证”操作

日期：2026-08-08  
状态：待实施（PDF 整体需求已纳入背景，本次先实施设置项视觉调整）

## PDF 整体优化需求理解

本 PDF 描述的不是单纯换颜色，而是对现有经典三栏笔记工作区进行第二阶段的信息架构、操作层级和内容密度优化。完整目标如下：

### 左侧导航栏

- 将“全部”和“未分类”作为更清晰的资料库入口，并显示记录数量。
- 在总范围内继续区分笔记和密码两类记录。
- “我的文件夹”单独成组，文件夹显示图标、名称和记录数量。
- 提供图标式新建文件夹入口，已有文件夹支持重命名。
- “最近删除”固定在左栏底部，作为独立的低频入口。
- 增加左栏折叠按钮，折叠后释放空间给中栏和正文。

### 中间列表栏

- 中栏顶部增加排序入口和紧凑的新建笔记入口。
- 列表仅承担浏览、搜索和选择，不放复制、分享、编辑、删除等记录级操作。
- 默认按最近更新时间排序，并预留最近创建、标题排序等方式。
- 列表行显示标题、摘要、记录类型、文件夹和时间信息，保持稳定行高。

### 右侧阅读与编辑区

- 正文顶部的复制、分享、编辑、更多操作改为低噪声图标按钮，并保留无障碍名称。
- 编辑不再使用独立的居中弹窗，而是在正文区域原地切换为编辑状态。
- 编辑状态包含标题、文件夹、Markdown 工具栏、正文、图片粘贴/拖放、保存和取消。
- 图片继续在客户端加密，不改变现有附件安全流程。

### 密码记录展示

- 密码字段改为更紧凑的字段名、内容、复制图标排列，尽量减少垂直占用。
- 密码值默认隐藏，保留显示/隐藏和逐字段复制。
- 普通字段和自定义字段使用统一布局，备注允许多行。
- 密码秘密值不能出现在列表摘要中。

### 最近删除

- 删除从直接永久删除改为先进入“最近删除”的软删除流程。
- 最近删除记录可恢复或永久删除；恢复时原文件夹不存在则回到“未分类”。
- 普通列表、搜索和文件夹计数排除已删除记录。
- 软删除不能立即清理附件，永久删除时才清理相关附件。
- 最近删除记录不允许创建分享链接。

### 安全边界

上述改版不得改变 PBKDF2、AES-GCM、`enc:v1`、Vault 隔离、30 分钟锁定、Authenticator、D1/R2 密文和附件格式、阅后即焚分享，以及异步读取的最新操作校验。最近删除若实施，需要通过密文状态和服务端删除标记扩展数据模型，不得保存笔记正文或密码明文。

本次文档对应的实施项仅为设置抽屉中的“关闭二次验证”视觉降权；其余 PDF 需求属于后续独立实施阶段。

## 目标

降低设置抽屉中“关闭二次验证”的视觉权重，避免它与主要安全操作竞争注意力，同时保留可发现性、键盘操作能力和现有安全确认流程。

## 设计

- 将 `disableTotpBtn` 从 `.security-panel-actions` 的主要操作区域移到安全验证卡片底部。
- 按钮表现为小号、灰色的次要文字操作，不使用红色背景、大面积填充或主要按钮尺寸。
- 当二次验证未启用时，继续沿用当前逻辑隐藏该操作。
- 点击行为、确认提示、请求接口、错误反馈和成功后的状态刷新保持不变。
- 危险语义在用户点击后的确认步骤中体现，不在设置首页持续使用高警示视觉。

## 文件范围

- `public/index.html`：调整按钮所在的结构位置并增加低权重样式类。
- `public/styles.css`：增加安全区底部次要操作样式。
- `test/index.spec.ts`：验证按钮位于主要操作区之外，并保留原有元素 ID。

## 非目标

- 不修改 TOTP 开启、关闭或验证 API。
- 不修改确认文案和认证状态管理。
- 不调整“退出登录”按钮。
- 不新增更多菜单或高级设置折叠层。

## 验收标准

1. “关闭二次验证”不再显示为安全卡片中的红色大按钮。
2. 操作位于安全卡片底部，使用灰色小号文字按钮。
3. 已启用二次验证时仍可找到并触发该操作。
4. 未启用二次验证时仍保持隐藏。
5. 原有确认、关闭请求和错误反馈行为不变。
